# 김소희 자기소개 페이지

HTML/CSS/JS로 만든 자기소개 페이지와 FastAPI 백엔드를 연동한 프로젝트입니다.

## 제출 주소

| 제출 항목 | 주소 |
|---|---|
| GitHub 저장소 주소 | https://github.com/365526/MY_PAGE |
| Vercel 배포 페이지 주소 | https://my-page-ochre-five.vercel.app |
| 백엔드 Swagger UI 주소 | https://mypage-backend-c3ui.onrender.com/docs |

## 주요 구성
- **프론트엔드** (Vercel): 자기소개 페이지. 백엔드 API를 호출해 소개 정보를 받아와 카드에 표시
- **백엔드** (Render): FastAPI로 구현한 소개 정보 API (`GET /profile`) · 소스 코드: https://github.com/365526/MYPAGE_BACKEND
- **소개 내용**: 프로필 · 관심 연구 주제 · 학기 프로젝트 · 이번 학기 목표

※ 첫 접속 시 응답이 지연될 수 있습니다. (Render 무료 플랜)
